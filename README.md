# IT爱学堂-Vibe Coding全栈开发实战训练营
获课：aixuetang.xyz/24230/

工具链选型与实战项目——构建你的 AI 开发武器库
Vibe Coding 的效果，一半靠流程，一半靠工具。课程中推荐的工具链覆盖了从需求分析到部署上线的完整链路，不同背景的学习者可以根据自己的情况选择合适的组合路径。
需求分析阶段：Claude、ChatGPT、豆包、DeepSeek 等大语言模型，用于生成产品需求文档，明确核心功能、目标用户、数据结构和 MVP 边界。
UI 原型阶段：v0.app 专注于生成高质量的 React + Tailwind CSS 组件，帮助你快速确认视觉方向。
代码生成阶段：非技术用户推荐使用 Lovable，它采用固定的技术栈（React + Tailwind + Supabase），对话式构建应用，上手门槛极低；有编程基础的用户推荐使用 bolt.new，它支持 Next.js、Vue 等多技术栈，可以在浏览器内直接运行 Node.js；国内开发者还可以选择字节跳动出品的 Trae，中文理解准确率高，基础版免费。
后端与数据库：Supabase 提供 PostgreSQL 数据库、Auth 认证、Storage 存储及 Edge Functions 服务，Lovable 支持一键连接，bolt.new 通过环境变量配置即可接入。
迭代调试阶段：UI 样式和文案修改直接在 Lovable 或 bolt.new 的对话框中完成；跨文件重构和复杂 Bug 修复则推荐使用 Cursor Composer 或 Claude Code，它们支持对整个代码库的理解和跨文件编辑。
部署上线阶段：前端和全栈应用推荐使用 Vercel，支持 Lovable 一键部署，自动配置域名、SSL 和 CDN；需要后端容器或 WebSocket 的项目可以使用 Railway；静态网站则可以选择 GitHub Pages 或 Netlify。
课程中设计了多个实战项目，从简单到复杂，覆盖不同的应用场景：个人简历页面、计算器、待办事项列表、天气查询页面、个人博客、记账小程序、贪吃蛇游戏、电商商品展示页、聊天室、企业官网等。 每个项目都有明确的难度标注和学习目标，帮助学习者循序渐进地掌握 Vibe Coding 的核心技能。
更重要的是，课程强调"不要盲目追逐工具"。工具迭代的速度远超学习速度，真正需要提升的是认知——对需求的深刻理解、对系统架构的把握、对人机协作边界的判断。 未来或许只需一个好想法，就能完成开发、修 Bug、搭建后端、落地正式产品，甚至实现自动获客和自动交易。到那时，人与人之间的差距，不再是谁会用更多工具，而是谁有更鲜活的创意，谁对需求有更深刻、更精准的认知。
